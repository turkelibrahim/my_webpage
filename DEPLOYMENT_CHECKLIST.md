# Yayın Kontrol Listesi

- [ ] Beş seçilmiş GitHub repository bağlantısı doğru
- [ ] Proje açıklamaları ve teknoloji etiketleri son kez gözden geçirildi

- [ ] Bireysel / ekip katkısı iddiaları proje bazında doğrulandı

- [ ] Sertifika bağlantıları tek tek açılıyor
